# خلاصه مدیریتی (Executive Summary)

## 1) پروژه چه می‌کند؟
پروژه «Gravity Technical Analysis» یک سرویس تحلیل تکنیکال (Microservice) است که:
- ورودی OHLCV (کندل‌ها) را دریافت می‌کند (یا از دیتابیس TSE می‌خواند).
- مجموعه‌ای از اندیکاتورها و تحلیل‌ها را محاسبه می‌کند (Trend/Momentum/Volume/Volatility/Cycle/Support-Resistance).
- تحلیل‌های مکمل (Candlestick Patterns، Elliott Wave، Market Phase) را تولید می‌کند.
- با یک موتور تجمیع سیگنال (Signal Engine) خروجی نهایی `overall_signal` و `overall_confidence` را ارائه می‌دهد.
- در صورت فعال‌بودن ingestion، خروجی‌های تحلیلی را در پایگاه داده ذخیره می‌کند و/یا رویداد منتشر می‌کند.

## 2) خروجی‌های کلیدی محصول
- **خروجی تحلیلی کامل**: `TechnicalAnalysisResult` شامل لیست اندیکاتورها + الگوها + فاز بازار + سیگنال نهایی.
- **خروجی اندیکاتورهای انتخابی**: محاسبه فقط چند اندیکاتور درخواستی.
- **تشخیص الگوهای هارمونیک**: (Gartley / Butterfly / Bat / Crab) + (اختیاری) امتیاز ML و هدف/حدضرر پیشنهادی.
- **پایش سلامت/متریک‌ها**: `/health*` و `/metrics` برای مانیتورینگ.

## 3) مشتری/کاربر هدف و سناریوهای استفاده
- تیم تحلیل یا ابزار تصمیم‌یار (مثل n8n/Agent) برای تولید سیگنال روزانه/هفتگی روی نمادها.
- سرویس‌های دیگر برای دریافت تحلیل با API.
- استفاده در Batch برای محاسبه امتیازهای تاریخی و ذخیره در Postgres جهت گزارش‌گیری/یادگیری ماشین.

## 4) نقاط تمایز فنی (برای ارائه سازمانی)
- تجمیع چند-بعدی سیگنال با وزن‌دهی و تطبیق وزن‌ها بر اساس «اعتماد/کیفیت خروجی هر دسته».
- پیاده‌سازی طیف گسترده‌ای از اندیکاتورها با خروجی استانداردشده `IndicatorResult` و `confidence`.
- قابلیت Pipeline کامل: Ingestion SQLite → Migration Postgres → Batch Analysis → ذخیره‌سازی قابل گزارش.
- معماری سرویس‌گرا با قابلیت فعال/غیرفعال کردن مؤلفه‌ها (Cache/Events/Scenarios/DB Explorer/Metrics).

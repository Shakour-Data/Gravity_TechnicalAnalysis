# GravityTseHisPrice Web Interface

این پروژه اکنون دارای یک رابط کاربری وب زیبا و کاربرپسند است که تمام قابلیت‌های سیستم را به صورت تعاملی در اختیار کاربران قرار می‌دهد.

## 🚀 راه‌اندازی سریع

### ۱. نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### ۲. راه‌اندازی دیتابیس
```bash
python main.py create-db
python main.py load-initial
python main.py load-all-prices
```

### ۳. اجرای داشبورد وب
```bash
python run_dashboard.py
```

### ۴. دسترسی به داشبورد
باز کنید: `http://127.0.0.1:8050/`

## 📊 ویژگی‌های داشبورد

### 🎯 کارت‌های خلاصه
- **🏢 تعداد شرکت‌ها**: نمایش تعداد کل شرکت‌های موجود در دیتابیس
- **📊 تعداد رکوردهای قیمت**: نمایش تعداد کل رکوردهای قیمت ذخیره شده
- **🏭 تعداد بخش‌ها**: نمایش تعداد بخش‌های مختلف بازار
- **📅 آخرین بروزرسانی**: نمایش تاریخ آخرین بروزرسانی داده‌ها

### 📈 نمودارها و تحلیل‌ها

#### نمودار قیمت
- انتخاب نماد مورد نظر از لیست کشویی
- نمایش روند قیمت تعدیل شده در طول زمان
- نمایش حجم معاملات به صورت همزمان
- امکان مشاهده روند عمومی بازار (میانگین همه شرکت‌ها)

#### نمودار توزیع بخش‌ها
- نمایش توزیع شرکت‌ها بر اساس بخش‌های مختلف بازار
- نمودار دایره‌ای تعاملی با درصد هر بخش

### 📋 جداول اطلاعاتی

#### جدول شرکت‌های پرمعامله
- نمایش ۱۰ شرکت پرمعامله بر اساس حجم معاملات
- شامل نماد، نام شرکت، حجم میانگین و قیمت میانگین

### 🎛️ عملیات سریع
- **🔄 بروزرسانی داده‌ها**: شروع فرآیند بروزرسانی داده‌ها
- **📊 گزارش وضعیت**: نمایش گزارش کامل وضعیت دیتابیس
- **🗃️ پشتیبان‌گیری**: ایجاد پشتیبان از دیتابیس

## 🔌 API برنامه‌نویسی

برای دسترسی برنامه‌نویسی به داده‌ها:

```bash
python web/api.py
```

API در آدرس `http://127.0.0.1:5000/` قابل دسترسی است.

### نقاط پایانی API:

#### `GET /api/summary`
خلاصه آمار بازار
```json
{
  "status": "success",
  "data": {
    "companies": 1234,
    "price_records": 567890,
    "latest_update": "2025-12-08",
    "sectors": 45
  }
}
```

#### `GET /api/companies?sector_id=27&limit=50`
لیست شرکت‌ها با امکان فیلتر بر اساس بخش
```json
{
  "status": "success",
  "data": [
    {
      "ticker": "ABC",
      "name": "شرکت نمونه",
      "sector_id": 27,
      "sector_name": "فلزات اساسی"
    }
  ]
}
```

#### `GET /api/price-data/ABC?limit=100`
داده‌های قیمت یک نماد خاص
```json
{
  "status": "success",
  "ticker": "ABC",
  "data": [
    {
      "date": "2025-12-08",
      "adj_open": 1000,
      "adj_high": 1050,
      "adj_low": 950,
      "adj_close": 1020,
      "adj_final": 1020,
      "adj_volume": 1000000
    }
  ]
}
```

#### `GET /api/sectors`
لیست بخش‌های بازار
```json
{
  "status": "success",
  "data": [
    {
      "sector_id": 27,
      "sector_name": "فلزات اساسی",
      "company_count": 156
    }
  ]
}
```

#### `GET /api/market-indices?limit=50`
داده‌های شاخص‌های بازار

#### `GET /health`
بررسی سلامت سیستم

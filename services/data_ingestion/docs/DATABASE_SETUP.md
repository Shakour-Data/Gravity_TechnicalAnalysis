# راه‌اندازی دیتابیس TSE

این راهنما نحوه ساخت و راه‌اندازی دیتابیس را توضیح می‌دهد.

## روش 1: راه‌اندازی کامل (توصیه می‌شود)

برای راه‌اندازی کامل دیتابیس از ابتدا:

```bash
python init_db.py
```

این دستور:
- ✅ تمام جداول را می‌سازد
- ✅ داده‌های پایه (sectors, markets, panels, companies) را بارگذاری می‌کند
- ✅ دیتابیس را برای جمع‌آوری داده آماده می‌کند

## روش 2: تنها ساخت جداول

اگر فقط می‌خواهید جداول را بسازید بدون بارگذاری داده:

```bash
python fix_db.py
```

## مراحل بعدی

بعد از راه‌اندازی دیتابیس:

### 1. بارگذاری شاخص‌های بازار
```bash
python main.py load-market-indices
```

### 2. بارگذاری شاخص‌های صنعت
```bash
python main.py load-sector-indices
```

### 3. دریافت داده‌های قیمتی
```bash
python main.py fetch
```

## بررسی وضعیت دیتابیس

برای بررسی وضعیت کامل دیتابیس:

```bash
python check_database_status.py
```

## ساختار دیتابیس

دیتابیس شامل جداول زیر است:

### جداول اصلی
- `companies` - اطلاعات شرکت‌ها
- `sectors` - صنایع
- `markets` - بازارها (اول، دوم)
- `panels` - تابلوها

### جداول داده‌های قیمتی
- `price_data` - قیمت‌های تاریخی سهام
- `market_indices` - شاخص‌های بازار (OHLC)
- `sector_indices` - شاخص‌های صنعت (OHLC)
- `usd_prices` - قیمت دلار

### جداول کمکی
- `indices_info` - اطلاعات شاخص‌ها
- `last_updates` - آخرین به‌روزرسانی‌ها

## نکات مهم

⚠️ **قبل از اجرای `fix_db.py` یا `init_db.py`:**
- یک backup از دیتابیس موجود تهیه می‌شود
- تمام جداول indices پاک و دوباره ساخته می‌شوند
- باید دوباره داده‌های indices را بارگذاری کنید

✅ **برای راه‌اندازی اولیه از `init_db.py` استفاده کنید**
